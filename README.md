# 教育支援キャラクター育成アプリ

小〜高校生が「学習・生活・趣味」などの情報を入力すると、その内容に合わせた自分専用キャラクターが育成される Web アプリ。キャラ画像は将来 Gemini API で生成する想定です。

## 目的・対象

| 項目 | 内容 |
|------|------|
| 目的 | 児童・生徒の学習状況・生活・趣味などを記録し、それに紐づいたキャラクターを表示することで、記録の継続や自己理解を促す |
| 対象ユーザー | 学生（小〜高校生） |

## 主な機能

- **ログイン（プロフィール登録）** … 名前・学年・得意教科・趣味を入力し Firebase に保存。初回のみ表示。
- **ホーム** … プロフィールからキャラ説明文を組み立て表示。将来は Gemini API で画像生成。
- **記録** … 日付・学年・名前・メモを Firebase の `memos` に保存。
- **関連ニュース** … 興味・学習分野に合わせたニュース（現状はサンプル固定表示）。
- **学習** … 今後コンテンツを追加する画面（現状はプレースホルダ）。
- **設定** … 登録データの表示とログアウト。

## 画面構成・ナビゲーション

- フッターナビ: **home / ニュース / 記録 / 学習 / 設定**
- 初回: `login-first.html`（プロフィール登録）→ 保存後 `index.html` へ遷移。
- 2回目以降: 直接 `index.html`（メイン画面）。

## 技術スタック

| 分類 | 技術 |
|------|------|
| フロント | HTML, CSS, JavaScript (jQuery 3.7) |
| バックエンド | PHP |
| DB・連携 | Firebase Realtime Database |
| 外部 API | Gemini API（キャラ画像生成） |
| デプロイ | Firebase Hosting |

## チーム体制・役割（4人想定）

### フロントエンド（2名）

| 役割 | 担当範囲 |
|------|----------|
| フロント1 | ログイン・ホーム・共通レイアウト（HTML/CSS/JS）、フッターナビ、Firebase 連携（プロフィール・認証） |
| フロント2 | 記録・ニュース・学習・設定画面（HTML/CSS/JS）、記録一覧・ニュース表示、設定・ログアウト |

### バックエンド（2名）

| 役割 | 担当範囲 |
|------|----------|
| バックエンド1 | Firebase 設定（Realtime Database ルール・認証）、環境構築・デプロイ、PHP 開発サーバー・ルーター |
| バックエンド2 | Gemini API 連携（PHP プロキシ）、画像生成エンドポイント、API キー管理・.env |
